# Cartinha para Larissa 💜

Site romântico estático, pronto para publicar no GitHub Pages.

## Como visualizar
Abra `index.html` no navegador ou publique os arquivos no GitHub Pages.

## Músicas
O site já inclui uma playlist fixa com exatamente três músicas:
- `assets/musica1.mp3`
- `assets/musica2.mp3`
- `assets/musica3.mp3`

Ao abrir a página, o site tenta iniciar a primeira música automaticamente e passa para as próximas em sequência. Alguns navegadores bloqueiam áudio automático com som; nesse caso, basta tocar em **“Toque aqui para ouvir as músicas”**. Isso é uma restrição do navegador, não do site.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste ZIP (não envie apenas o ZIP).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o GitHub gerar o endereço do site.

## Personalizar
- Fotos: substitua `assets/foto1.png`, `assets/foto2.png` e `assets/foto3.png`, mantendo os mesmos nomes.
- Músicas: substitua os três MP3 mantendo os nomes.
- Texto: edite o conteúdo de `index.html`.
- Cores e visual: edite `style.css`.
